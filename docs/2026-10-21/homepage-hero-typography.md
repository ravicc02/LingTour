# 首页标题字体修订

> 日期：2026-10-21（Asia/Shanghai）
> 依据：首页字体批注与用户提供的三行大字参考图。

## 范围与决定

保留 main 当前首页、原文案、照片与两个入口。只调整主标题字体和排版。此前暂存的 `codex/homepage-ticket-hero` 保持原状。

以用户最后提供的图片为视觉依据：三行同级大字、左对齐、紧凑行距；中间一行金色斜体。首两行用大写首字母显示，保留 culture voyage to China 的原始文本。

采用项目现有 Trebuchet MS / Segoe UI 无衬线字体栈，字重为 500。取消错位缩进、不同层级的字号和落款装饰；不新增字体依赖。

## 实现

标题通过独立 CSS Module 调整字号、行距、字距与强调色。保留单个 H1、原有动画与连续文本顺序。

桌面使用更大的标题比例；手机收紧字号，确保每行完整、字母下降部不裁切、两个入口可见。
