# 前台组件与排版统一打磨

> 日期：2026-10-21（Asia/Shanghai）
> 分支：codex/browser-feedback-2026-10-21
> 范围：当前 public site 的共享组件与页面布局；后台与 API 不在本轮视觉修订范围内。

## 设计依据

使用用户指定的 finesse-ui，按 redesign 流程先审查再修改。已读取 PRODUCT、DESIGN、响应式规范及当前更新记录。对 16 个路由、桌面和手机共 32 组页面做了基线审查，并保存六个主栏目的截图。

当前主要问题为高频彩色纹理抢占注意力，卡片阴影和边框层级不一致，说明文字大面积斜体，筛选栏及按钮的间距不统一，部分页面留白重复叠加。基线发现 Routes 手机横向溢出，以及商品总览与社区搜索的 14 px 字号；已有交互与内容需要继续保持。

你会看到：细而一致的纸张纹理、清晰的标题和正文层级、整齐的图文卡片、更好用的筛选与表单，以及在手机上连贯的滚动和操作。

采用既有纸张、河墨、朱红与金色，不更换字体族。保留首页三行标题、City Culture / Story Routes 金色标题、城市详情原 Hero、正文阅读布局、地图卡片外移，以及刚恢复的 Choose support / Rates。保留所有文案、金额、图片和业务入口。

## 审查中的具体修正

Routes 手机溢出来自卡片中的绝对定位 `sr-only` 元数据标签。卡片没有建立定位参照，标签逃逸到滚动轨道外。将卡片设为 `position: relative`，让元数据标签受本卡片与横滑轨道约束，不用额外裁掉页面内容。

商品总览和社区工具栏接入统一表单字号，手机输入与选择框保持 16 px。口译日历在窄屏使用底部定位面板，并为 320 px 视口调整内边距和网格，保留日期选择与 Escape 行为。


字体审查发现：旧 DESIGN 声明公共大标题统一 Georgia，但浏览器中已确认的栏目标题实际使用现有人文无衬线字族，登录页使用显式 Georgia。按用户先前确认的标题保留实际字形，不借本轮修复字体声明来切换外观；将设计说明更新为实际使用边界。


对比度复核：既有 gold 在浅纸面上约为 3.76:1，适用于大标题和装饰。城市标签与服务适用人群等小字号改用现有 muted 色；照片上的专长文字使用已有 gold-light。金色操作按钮保留背景，前景用白色保证小字号可读，悬停仍沿用原深色前景。


日历交互回归发现：原初始化 effect 会把无活动日期强制改回首个活动日。修复为仅在尚未选择日期、异步活动数据首次到达时初始化；用户选择及数据刷新不再重置日期。新增两个回归测试，先复现失败，再验证无活动日期和异步刷新场景。该改动只影响前端选择状态，不写入活动数据。
