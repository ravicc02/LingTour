## 2. 实施结果

### 首页、地图与匿名 Ticket

- Hero 改为居中 Culvoy 字标；三个入口为 Cultural Information、Route Planning、Interpretation，仍使用 `/culture`、`/routes`、`/interpreting`。
- 顶部、移动菜单及页脚术语同步；移动菜单保留 Escape、焦点恢复，并隔离背景交互。
- 保留首页商品区及购买/收藏链路；原口译介绍位置换为 Ticket，不删除独立口译页。
- 地图沿用真实广东几何与城市关联；增加 China/Guangdong 及实际城市搜索，Know more 与路线/口译动作携带 citySlug。无内容时明确空状态，不补造城市或跳到别处。
- 匿名访客选择真实城市、可选昵称/日期/短句，在浏览器生成预览及 2400 × 1500 PNG；二维码由实际 QR 编码库生成，指向城市公开页面。个人输入不写数据库、不通过网络发送。
- 图片使用同源受限 relay：只接受城市 slug，核对公开城市与真实主图/视频封面，限制媒体来源、格式、重定向、超时及大小。失败不返回假图。
- 真实浏览器下载、字体、二维码扫描及截图未完成；canvas mock 和 QR 库测试不作为实际 PNG 验收。

### 服务请求、价格与后台匹配

- 免费固定路线请求、定制路线请求、口译请求三种独立路径，使用共用三步表单；从地图、路线、译员真实读取上下文，不默认填城市或服务日期。
- 固定路线提交保存真实预约模型，服务器记录 USD 0，不创建路线费或定金订单。食宿、交通、景区票等第三方成本明确不包含。
- 定制规划保存天数、意向、饮食、住宿及预算需求，由实际后台账号分配并提出独立 USD 规划报价。询价不是免费规划服务，也不擅自设定最低价或询价定金。
- 六个口译套餐由后端唯一来源提供并保存价格快照：固定路线 4/5/7 小时为 USD 305/375/525，定制路线口译为 USD 400/500/700。使用整数 cents，不做汇率转换。
- 偏好译员与实际分配分开；操作人员分配不自动宣称完成确认。总价、报价与支付状态分开。
- 免费路线的可选口译建立独立关联请求，不把免费路线收费化。
- 请求使用会话 userId 所有权及 owner-scoped 输入哈希幂等；客户端金额不是计价来源。
- **新付费 checkout 明确禁用**：`paymentPolicy=not_configured`、`checkoutEnabled=false`。没有猜测定金，没有把总价当定金，也没有给新 USD 请求沿用旧 SGD 定金。历史订单保留原币种/金额及既有 PayPal 对账逻辑。
- 后台保留历史预约，新增服务请求列表、结构化详情、真实运营账号分配、版本报价与消息处理。空筛选参数已修复，不会因严格 enum 验证导致默认列表 HTTP 400。

### 请求私人对话

- 请求本人和当前分配工作人员可访问文字会话；未分配管理员/编辑不能绕过会话权限。
- 请求行锁串行化分配、报价、消息与读取标记；支持时间、分页、未读、幂等重试，报价确认绑定确切版本。
- 重新分配后原处理人员失去会话访问权；新请求不能通过猜 ID 或同邮箱字符串认领。
- Profile Bookings 中展示新请求/报价/会话，旧预约继续单独保留。账号切换清理私有状态与迟到响应。
- 通知不广播私人正文；金额通知明确 USD 与未启用支付规则。

### 两套日历

- 首页公共日历默认 Asia/Shanghai Today，不再跟随第一条活动；空日期可选、手动日期/月不会被刷新覆盖，支持跨日/跨月重叠与完整分页。
- 现有左右/上下布局扩展多条活动内容、图片/视频、封面兼容、Slogan、补充信息及 Know more；不新增商家必填字段或招商系统，不恢复 sticky 错位。
- 新发布版本记录内容快照、日期范围、排序及操作记录；普通编辑不覆盖已发布快照。未来停展与管理员历史撤回分开，历史媒体保留并阻止直接删除。
- 旧公开活动接口保持兼容；日历中旧记录只用于今天/未来，且在首个有效版本之前可展示。不伪造上线前的历史。首次安排未来版本不会让今天内容提前消失。
- 后台未保存草稿继续通过可信 preview bridge 在真实公共日历中预览，并明确标示未发布。
- Profile 新增 Calendar；Notes/Routes/Collection/Bookings/Settings 保留。私人笔记使用独立本人 CRUD 与 private/no-store，允许同日多条，不同步社区/Ticket，无默认后台全量阅读页面或提醒。

### 社区及英文文案

- 新增稳定 citySlug/routeId/interpreterId，服务端在排序/分页前过滤；保留 location 自由文本，历史记录不猜测归属。
- 城市/路线/译员相关帖子只读取对应关联；细分 location 只预填发帖，不错误限制整个城市关联 Feed。筛选、搜索、排序、分页和登录返回保留上下文。
- 可访问的 + 发帖入口；新帖继续待审核。路线待审帖子不写入本地公开 Feed，明确提示审核后展示。
- 真实体验标记由后台核对已完成、作者本人、所有关联一致的服务记录；公开响应不泄露证据预约 ID、联系方式或审核信息。
- 重点操作及页面英文文案精简，保留费用、隐私和错误提示；技术路径及历史兼容 key 不机械重命名。CMS 已有正文继续原样展示，未修改生产文案。

## 6. 保留的业务决策与限制

1. 品牌最终大小写待确认，本轮沿用 Culvoy，没有替换品牌资产。
2. 定制规划按真实人员逐请求报价，没有擅自设定统一最低价或询价定金。
3. 口译定金金额/比例、支付时点、取消退款与包含范围待确认；新 paid checkout 关闭，不能将本轮视为完整付款上线。
4. 规划员由现有真实后台人员承担，不新造规划员角色或账号；专门角色/权限策略可另行批准。
5. 免费固定路线具体履约及容量仍待运营确认；文案不暗示第三方成本免费。
6. 账户删除目前匿名化 users 行，私人笔记/请求/消息不会因外键自动删除；上线前需批准保留/擦除政策。本轮没有未经授权清除数据。
7. 暂未完成真实浏览器视口/键盘/媒体播放/匿名 PNG，或数据库迁移后的 E2E。本轮不提供假的截图、保存成功或支付成功报告。
8. 商品价格不属于口译套餐定价范围，未批量换 USD。生产 CMS 旧 FAQ/服务正文仍照现有内容读取；如存在过时价格/退款文案，须按内容发布审批单独整理，不能默认以本轮授权改写生产数据。
