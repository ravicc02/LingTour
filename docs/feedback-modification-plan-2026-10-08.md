## 4. 固定路线、定制路线与口译

### 4.1 三条独立路径

**固定路线免费预约**

Route Planning → Free Routes → 固定路线详情 → 免费预约 → 后台接收与确认。

- 路线预约金额 USD 0，不强制创建定金订单，不跳转支付。
- 必须有真实预约提交、后台记录与状态，不能退化为只浏览路线内容。
- 用户可以单独选择付费口译；固定路线免费与口译收费必须明确分开。
- 食宿、交通、景区门票等第三方费用不应被暗示为全包免费；具体服务包含范围仍需说明。

**收费定制路线**

Route Planning → Custom Routes → 提交需求 → 后台分配规划员 → 对话与报价 → 用户确认 → 按规则付款。

- 定制路线不是免费服务；仅询价是否收定金尚待确认。
- 定制路线规划费用与口译套餐费用分开建模，不把下面的口译套餐当成定制路线规划总价。

**付费口译**

Interpretation → 选择套餐/偏好译员 → 提交需求 → 匹配确认 → 按规则付款。

- 保留译员展示与资料。
- 偏好译员是用户请求，不应在提交时宣称已成功分配。

### 4.2 共用表单骨架

表单显著标识 Free Route Booking / Custom Route Request / Interpretation Request。建议三步：Trip details、Requirements、Contact & review。

| 字段 | 免费固定路线 | 定制路线 | 口译 |
| --- | --- | --- | --- |
| 城市、日期、人数、姓名、联系方式 | 必填；路线可预填 | 必填；日期规则可按业务细化 | 必填 |
| 固定路线 ID | 必填 | 可选参考 | 选固定路线套餐时必填 |
| 天数、意向景点/饮食、住宿、预算 | 不要求填写完整定制需求 | 结构化收集 | 按需要选填 |
| 小时套餐、路线类型 | 不要求；加购口译后出现 | 不等于规划费用 | 必填 |
| 语言组合、服务场景、偏好译员 | 加购口译时出现 | 可选附加服务 | 必填/选填按字段定义 |
| 补充说明 | 选填 | 选填 | 选填 |

- 从地图、路线、译员进入时真实读取并预填上下文。
- 不擅自默认城市或补造用户未填的服务日期。
- 切换服务类型保留共用字段，清空失效套餐和专属字段。
- 提交摘要明确展示免费/收费、USD 总价与定金（如适用）。
- 使用防重复提交、字段验证、状态反馈与失败重试；客户端金额不是计价依据。

### 4.3 已确认美元口译套餐

用户已明确要求原人民币数字直接改成美元。这是定价决策，不是汇率换算。

| 服务时长 | 固定路线口译套餐价 | 定制路线口译价格 |
| --- | ---: | ---: |
| 4 小时 | USD 305.00 | USD 400.00 |
| 5 小时 | USD 375.00 | USD 500.00 |
| 7 小时 | USD 525.00 | USD 700.00 |

- 保留 305，不推算或修正为 300，不做汇率换算。
- 不默认有折扣、划线价或促销；“原价”展示规则尚未明确。
- USD 是固定计价币种，不随访问者地区/所选城市变化。
- API 使用整数 cents：30500、40000、37500、50000、52500、70000。
- 套餐结构包含 ID、时长、适用路线类型、currency=USD、金额、启用状态和定金规则。

## 9. Ticket：公开入口替换首页口译位置

### 9.1 权限与位置

这是用户已确认要求：任何公开访客均可在首页原口译板块位置进入并生成漂亮的城市 Ticket。

- 不检查登录、购买、预约、付款或行程完成。
- 不要求上传订单/到访证明，不仅对买过服务的用户开放。
- 手机与桌面入口同等可见；不能登录后才出现。
- Ticket 是纪念图，不是景区门票、支付凭证或到访认证。

### 9.2 首版流程与设计

选择真实城市 → 可选昵称/日期/短句 → 预览 → 下载高清 PNG。

建议票面包含品牌、城市名与真实城市图片、所选日期、可选昵称/短句、纪念编号、城市文稿二维码；采用一致的票券设计、清晰字体和克制装饰。生成不依赖实时 AI，先使用确定性模板保证质量和稳定性。

首页入口可使用 Make your city ticket；必要的一句说明即可，不增加长宣传文案。建议由首页内生成面板承接，不强制新增整个独立工具站。

### 9.3 技术边界

- 优先浏览器内生成与导出，匿名输入不默认写入公共数据库。
- 预加载字体与同源/CORS 可导出的媒体，处理跨域 canvas、长名字、字体缺失与图片加载失败。
- 用户内容长度限制并安全渲染，不支持任意 HTML。
- 纪念编号不暴露私人请求 ID；二维码默认指向城市公开文稿，不含姓名/私人笔记。
- 账户收藏和公开分享链接不是首版必需，不能成为匿名下载前置。

## 12. 验收清单

### 首页与地图

- Hero 品牌居中，三个入口正确，导航/移动菜单/页脚术语一致。
- 首页商品区仍在；原口译区被 Ticket 入口替换；独立口译/商品页面可用。
- 城市切换后文稿、路线、口译上下文正确，无错城、死链、手机横向溢出。

### 免费路线与付费服务

- 固定路线可真实免费预约，后台看到记录，无强制付款或定金。
- 可选口译加购独立收费；不把整个固定路线预约显示为付费。
- 定制路线可提交结构化需求，规划员接收、匹配、沟通与报价。
- 4/5/7 小时两类口译价格分别为 USD 305/375/525 与 USD 400/500/700。
- 前台、API、后台、新订单、付款请求及通知均为 USD；总价和定金分别显示。
- 修改客户端金额不能改变后端价格；历史非 USD 订单仍以原币种处理。

### 两套日历

- 固定日期为 2026-10-08 时，首页默认 October 2026 且选中 8 日，不跟随活动第一条。
- 数据刷新不覆盖选中日期，空日期不跳回，跨月/跨日活动与分页完整。
- 原日历右侧可看多条图片/视频及 Event/Slogan/信息，不要求商家名称，无独立招商系统。
- 发布某日两条内容，再修改新版本，回看旧日期仍保持当日版本与媒体。
- Profile Calendar 保存后刷新仍存在；两用户互不可读，首页和社区不会泄露私人笔记。

### 社区、对话与 Ticket

- 城市 Feed 只显示该城市帖子；搜索、排序、分页、发帖返回不丢上下文。
- 城市/路线/译员相关帖子关联准确，新帖遵守现有审核流程。
- 用户与分配工作人员可完成对话，其他用户或无权工作人员不能访问。
- 未登录、未购买访客可完成 Ticket 预览和下载；高清图、字体、图片、二维码完整。

### 验证方法

实施阶段先写关键规则回归测试，再执行三端类型检查、目标测试、非自动修复 lint 与构建；最终模拟真实浏览器流程。重点覆盖零费用预约、套餐后端计价、权限越权、历史快照和匿名图片导出。本轮没有执行这些测试。
