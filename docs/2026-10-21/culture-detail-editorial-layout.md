# Culture 详情页阅读排版修订

> 日期：2026-10-21（Asia/Shanghai）
> 分支：codex/browser-feedback-2026-10-21
> 范围：三个城市的 Culture 详情页、文章渲染、目录与图片查看。

## 设计依据

按用户指定使用 finesse-ui 的 redesign 流程，先审查现有排版，再调整密度和阅读节奏。旧正文栏仅 65ch 宽，图片最高 672px，图间留白和引用边距重复叠加。1355 × 944 下，三个城市正文高约 3749～4739px。

采用城市阅读手册的布局：保留品牌字体与颜色，保留原来的 Hero，仅缩小章节照片；以目录、图文并排和紧凑引用提高每屏信息量。沿用现有 CMS 素材，不生成或下载新图，不增加填充文案。

## 实现决定

- 根据用户最终反馈，Hero 恢复原有大图、标题、日期和标签布局，保留原照片边框、底纹、手机叠放和发帖入口。正文继续使用本次新排版。
- 根据后续反馈，正文、关联区域、城市翻页和吸顶目录复用 Hero 的 `bg-grain` 纹理与底色，统一整页材质。
- 保留全部 Markdown 正文、引用、事实行和图片。清洗后的语法树按作者的一、二级标题分章，每章正文与辅助照片并排。
- 桌面左侧增加章节目录；手机目录横向滚动。原文顺序保留在每个章节内，图片作为对应章节的辅助图版。
- 照片以缩略图呈现，提供原图放大查看；Esc 关闭、焦点返回，降低动态效果时保留完整终态。
- 原有 Markdown URL 校验、HTML 清洗、GFM、链接、表格和清单支持保留。布局转换放在清洗之后，不能让作者 HTML 注入目录或布局属性。
- 保留关联路线、周边城市、上一篇/下一篇和社区发帖入口。

## 验证

比对三个城市前后的原文块、图片和链接，确认内容完整。检查文章高度、图片高度和桌面/手机实际截图。验证目录跳转及选中态、图片放大、Esc 与焦点返回、关联入口、后台预览、空内容和单章节情况。

增加必要的结构及安全回归测试；运行 site 类型、lint、测试与 Docker 构建。原生构建若有异常，保留诊断，不跳过类型检查。

## 结果与证据

Hero 的 JSX 与修订前逐字一致。正文、关联区域和翻页使用同一个页面纹理，吸顶目录复用同一纹理类。三个城市的 Hero、页面和目录，其背景图、平铺方式、纹理尺寸及底色均已在浏览器中比对一致。

在 1355 × 944 视口下，三个城市各保留 18 个原文块与 4 张图片。正文高度变化如下，Hero 不计入正文高度。

| 城市 | 原正文高度 | 新正文高度 | 缩短比例 |
| --- | --- | --- | --- |
| Chaozhou | 4057 px | 1484 px | 63.4% |
| Guangzhou | 3749 px | 1536 px | 59.0% |
| Zhanjiang | 4739 px | 1455 px | 69.3% |

正文图片最大高度由 672 px 收到 222 px，点击可查看完整原图。原有 CMS 素材与文案保持完整；本次未核验或替换图片选材。

验证结果：

- site 类型检查通过；完整测试为 23 个文件、119 个测试通过。纹理调整后重新运行相关 3 个文件、20 个测试通过。
- 完整 ESLint 为 0 errors、1080 warnings。新增及修改的 Culture 文件目标 lint 通过。
- 浏览器 11 项场景通过，覆盖三个城市内容比对、目录定位与选中态、图片放大及关闭、Esc、焦点返回、关联路线、城市翻页和原有发帖参数。
- 320、375、390、414、768、834、1024、1440、1920 px 共 9 个宽度未出现横向溢出。桌面和手机截图已人工查看。
- 纹理图、尺寸、平铺与底色在三个城市均一致；正文密度维持本次布局结果。正常动态及减少动态模式均可阅读，浏览器未捕获页面异常或业务写请求。
- finesse 静态检查为 0 个 P0。保留品牌已有纸张色 token 的 P2 提示，遵循用户要求的原配色和纹理。
- 92 份 Markdown 本地链接与 Git 空白检查通过。远程 CI 尚未触发。

本地 Docker 预览构建通过，3000 端口已更新。标准 Node 20 构建此前出现 TypeScript worker 原生崩溃；本次使用忽略目录内的 Node 24 builder 覆盖完成完整编译，运行阶段仍为 Node 20。仓库 Dockerfile 与 CI 未更改，类型检查未绕过。

关闭 JavaScript 时，文章章节和锚点已完整输出，但现有 Next.js 流式页面壳会将内容留在隐藏的 Suspense 容器内。本次没有修改页面壳，因此不宣称完整的无 JavaScript 阅读流程通过。

证据保存在忽略目录 `.local-backups/culture-detail-redesign-2026-10-21/`：`browser-report.json`、`finesse-report.json`、`lint-final.json`、`tests-final.log`、`build-matched-grain.log`，以及桌面、手机、平板和图片查看截图。
